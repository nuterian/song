A music video for any song.

Give it a track. It listens to the whole song, then draws it as a solar system where every beat, note and word moves something.

Make your own Watch the whole song

Then direct it yourself.

Change a shot, move a moment, or just ask. Export in 1080p when it is right.

# macOS, Apple Silicon git clone https://github.com/nuterian/song cd song && ./setup.sh python -m visuals studio

Free and open source. Everything runs on your Mac: no account, no uploads, no keys. The install is about 2 GB, plus free models it asks before fetching. A song takes a few minutes to prepare.
